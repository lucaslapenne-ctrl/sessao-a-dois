Sessão a Dois — Política de Privacidade

Última atualização: 13 de outubro de 2026.

O Sessão a Dois é um app gratuito e sem fins comerciais para registrar filmes, séries e animes assistidos em grupo.

O que coletamos

Ao entrar com o Google, recebemos apenas seu nome, e-mail e identificador da conta Google. Também guardamos o que você cadastra no app: as listas, os títulos, as notas, os comentários e o nome que você escolhe exibir.

Para que usamos

Só para fazer o app funcionar: identificar você no login e mostrar suas listas para você e para as pessoas que você convidou. Não vendemos, não compartilhamos com anunciantes e não usamos seus dados para publicidade.

Quem vê seus dados

Cada lista só é visível para seus membros. Quem entra numa lista vê os títulos, as notas e os nomes de exibição dos outros membros. Seu e-mail não é mostrado para os outros membros.

Onde ficam os dados

Os dados ficam armazenados no Supabase. As capas e informações dos títulos vêm da API do TMDB; este app usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.

Apagar seus dados

Você pode sair de qualquer lista pelo app, o que apaga suas notas nela. Para apagar sua conta e todos os seus dados, envie um e-mail para o contato abaixo.
